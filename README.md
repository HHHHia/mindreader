# Read You Like a Book

一个「机器怎么学会读懂你」的演示程序：你和电脑玩石头剪刀布，**五个预测模型同时在旁边看你出拳**。
每局 60 回合，局末程序告诉你「最好的那个模型读懂了你百分之多少」，并把你的可读性记进排行榜——
越容易被猜中，排名越靠前。

English version: [README.en.md](README.en.md)

里面没有神经网络，全部是计数统计：数你出过什么、上一步出什么、输赢之后怎么变。但它在 300 回合里
能把固定套路（R→P→S 循环、赢就重复）读到 95%~99%，而真随机出拳的人只有 30% 上下。
**差距不在机器，在被读的人。**

## 怎么玩

双击本目录的 `mindreader.exe`（或在命令行里于本目录执行 `mindreader.exe`）。

| 画面     | 操作                                             |
| -------- | ------------------------------------------------ |
| 标题页   | `ENTER` 开始                                     |
| 起名页   | 打字输名字（≤18 字符，不能含 `,`），`ENTER` 确认 |
| 游戏页   | `R` / `P` / `S`，或用鼠标点左侧三个按钮          |
| 结算页   | `ENTER` 再来一局　`L` 排行榜　`ESC` 退出         |
| 排行榜页 | `ESC` 返回结算页                                 |

- 每回合出拳后会停 0.85 秒，显示「你出什么 / 机器出什么 / 谁赢」，然后自动进下一回合。
- 右侧 **MODELS** 面板是实时的：每个模型当前的命中率、它这回合猜你会出什么；
  高亮那行是机器这回合实际信任的模型。
- **名字就是存档的键。** 同名再玩，机器接着上次的数据学，游戏页顶部会多一行
  `MEMORY: this machine has already watched you for N rounds`。

## 五个模型

| 模型      | 它假设什么             | 具体猜法                                   |
| --------- | ---------------------- | ------------------------------------------ |
| BASELINE  | 什么都不看             | 永远猜 ROCK，33% 的锚点                    |
| FREQUENCY | 你会重复自己最常出的   | 你出得最多的那个                           |
| MARKOV-1  | 你的下一步取决于上一步 | 「上次出 X 之后」你最常出什么              |
| MARKOV-2  | 取决于上两步           | 「前两步是 X,Y 之后」你最常出什么          |
| REACT     | 赢和输之后反应不同     | 「上一步出 X 且上回合赢了 / 没赢」分别统计 |

**机器怎么出拳**：每回合开始五个模型各给一个猜测，机器从中挑一个来参考，出它的反制。

**结算怎么判**：取所有模型中**最高的命中率**（命中数 / 试算次数）。

| 命中率  | 结算评价                                             |
| ------- | ---------------------------------------------------- |
| ≥ 50%   | `PREDICTABLE. you have a tell.` —— 有套路            |
| 40%~49% | `SOMEWHAT READABLE. a pattern is forming.`           |
| < 40%   | `UNREADABLE. the machine never got a handle on you.` |

## 数据存在哪

| 文件                       | 内容                                                       | 会不会被覆盖     |
| -------------------------- | ---------------------------------------------------------- | ---------------- |
| `data/players/<名字>.txt`  | 这个人的全部计数矩阵（`PROFILE 1` 格式），跨局累积，不重置 | 只在结算页写一次 |
| `data/leaderboard.csv`     | `名字,历史最高命中率,累计回合`，按命中率降序               | 每局结束时更新   |
| `run.log`                  | 最近一次启动的 raylib 日志                                 | **每次启动重写** |
| `data/` 与 `data/players/` | 首次运行自动创建                                           | —                |

想从头开始读你：关掉程序，删掉 `data/players/<你的名字>.txt`。
